# Dubai Prime Estates

A luxury real estate website concept designed and developed as a front-end portfolio project.

Dubai Prime Estates presents a modern property experience inspired by Dubai's premium real estate market, combining elegant visual design, responsive layouts, property showcases, area discovery, services, and an interactive contact experience.

---
## 🚀 Live Demo

View the live website here:

https://mozhgan-dev.github.io/dubai-prime-estates/


## ✨ Features

- Luxury responsive user interface
- Automatic hero image slider
- Featured property listings
- Dubai area showcase
- Real estate services section
- About section
- Contact enquiry form
- Front-end form validation
- Smooth scrolling navigation
- Responsive layouts for desktop, tablet, and mobile
- Interactive hover effects and transitions
- Elegant navy, gold, and neutral color palette

---

## 🏙️ Website Sections

### Home
A full-width visual hero slider introducing the luxury real estate experience.

### Featured Properties
A curated selection of premium apartments, villas, and penthouses.

### Explore Dubai
A visual showcase of some of Dubai's most desirable communities and locations.

### Services
Real estate services including:

- Buying Property
- Selling Property
- Property Investment
- Luxury Rentals

### About
An introduction to the Dubai Prime Estates concept and brand experience.

### Contact
A luxury enquiry section with contact information and an interactive front-end form.
